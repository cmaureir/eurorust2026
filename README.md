# EuroRust 2026

Slides for the talk:

> Rust's Influence on C++ and Python: Shaping the Future of Three Communities

Built with [reveal.js](https://revealjs.com) (git submodule), deployed to
GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Running it locally

```sh
git submodule update --init --recursive
python -m http.server 8000   # then open http://localhost:8000
```
